1.5. Introducing the nano editor¶

Nano is a simple and easy to use command line text editor. It is included as with most *nix systems and with Apple OS X. Among its features are:

  • simple commands

  • easy to use

  • support for hundreds of programming languages and file formats

1.5.1. Opening and Saving¶

To open a file using nano you type

nano file.txt

If the file exists, nano will open it, else it will create it. You might notice the list of commands at the bottom. On most systems it will look like this:

^G Get Help  ^O WriteOut  ^R Read File ^Y Prev Pg   ^K Cut Text  ^C Cur Pos
^X Exit      ^J Justify   ^W Where is  ^V Next Pg   ^U UnCut Text^T To Spell

On most systems, to save and exit, you type Ctrl and X. Then nano will ask if you want to save (Y or N) and will double check the file name.

That's it!

1.5.2. Creating ‘Hello World’ using nano¶

  1. Before jumping into the editor, first let’s plan to save our project in a directory of its own:

    host@user: mkdir work
host@user: cd work

    I chose to work in the directory, work, but you could have named it hello, project1, or anything else. Just pick something that works for you, preferably related to the task at hand. Recommendation: avoid spaces in directory names.

  2. At the command prompt, open a new cpp source file:

    host@user: nano hello.cpp

    You’ll now be in nano, which initially, will show a blank canvas. You can now begin typing your program:

    #include <iostream>

int main() {
  std::cout << "Hello, World!\n";
}

  3. When done typing, press CTRL X to exit.

  4. Save your work by typing Yand Enter.

  5. Type the following to compile your code:

    g++ hello.cpp   -o hello

  6. If you type ./hello and you didn't get any errors on the previous step, then you should see: 

    Hello, World!

1.5.3. Navigating to compile errors¶

It is inevitable that sometimes you will create a program that does not compile.

Given the following, almost correct version of our hello, world program:

#include <iostream>

int main() {
  cout << "Hello, World!\n";
}

Typing g++ hello.cpp -o hello results in:

g++ hello.cpp -o hello
hello.cpp:4:5: error: use of undeclared identifier 'cout'; did you mean 'std::cout'?
    cout << "Hello, World!\n";
    ^~~~
    std::cout
/usr/include/c++/v1/iostream:50:33: note: 'std::cout' declared here
extern _LIBCPP_FUNC_VIS ostream cout;
                                  ^
1 error generated.

Make a mental note of the line number and character location (ie 4:5), then open your code in nano using: nano +4,5 hello.cpp it will open the file and automatically put the cursor to the location of the error.

Note: If you want move to the location by hand, after opening nano you can use CRTL-C to show the current line number.

Protip: On most machines if you open your file with an extra -m like so: nano -m hello.cpp and then you can use your mouse to move around.
